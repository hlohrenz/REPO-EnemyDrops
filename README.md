# Enemy Drops

![Enemy Drops Preview](preview.gif)

## Overview
This mod gives enemies a configurable chance to drop a health pack when they die.

For now, health packs are the only planned drop item. If you want, more enemy drop types can be added later, but for now I only made it so health packs drop!

## Who Needs The Mod
Only the host needs the mod installed!

## Configuration Values
| Setting | Description | Default |
|---------|-------------|---------|
| `HealthPackChance` | Percentage chance (0-100) for an enemy to drop a health pack when it dies | `50%` |
